# Student Management System

## Overview

The Student Management System is a beginner-level Python project developed to manage student records through a simple menu-driven program.

The system allows users to add, view, search, update, and delete student information.

This project was developed to practice Python fundamentals and understand basic CRUD operations.

## Features

- Add a new student
- View all students
- Search for a student using Student ID
- Update student information
- Delete a student
- Exit the program

## Technologies Used

- Python
- Lists
- Dictionaries
- `for` loops
- `while` loops
- Conditional statements
- User input
- Basic CRUD operations

## Student Information

Each student record contains:

- Student ID
- Name
- Age
- Course
- Marks
